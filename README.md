# My Profile App

A simple React Native (Expo) app that shows a user profile screen with an avatar, name, email and points.

## Features

- Profile avatar with a verified check badge
- Displays user name, email and points
- Floating action button (FAB)
- Clean black and white UI

## Tech Stack

- React Native
- Expo
- JavaScript
- @expo/vector-icons

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org) (LTS)
- [Git](https://git-scm.com)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/inclass_05.git
   ```
2. Go to the project folder
   ```bash
   cd inclass_05/app
   ```
3. Install dependencies
   ```bash
   npm install
   ```

### Run the app

```bash
npx expo start
```

- Press `w` to open in the browser
- Press `a` to open in an Android emulator
- Or scan the QR code with the **Expo Go** app on your phone
